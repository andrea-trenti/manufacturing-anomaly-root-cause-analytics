# v3 Release Scope

This is a **research-grade synthetic manufacturing analytics study**. It is not OEM/Ferrari data, not a validated digital twin, and not an autonomous CAPA system. The v3 release freezes the scientific conclusions already validated in Parts 1-2 and focuses on persistence, reproducibility, claim governance and packaging.

The primary chain is: manufacturing events -> quality monitoring -> anomaly prioritization -> RCA evidence -> reliability -> CAPA counterfactual evaluation -> probabilistic economics.
