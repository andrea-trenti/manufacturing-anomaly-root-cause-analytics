# Reliability Protocol

MTBF/MTTR/availability are descriptive for repairable equipment. Weibull uses right-censored tails and is not treated as a universal repairable-system model. Crow-AMSAA/NHPP summaries remain separate. Joint quality-reliability analysis is retained as a negative/partial result: higher process variance was associated with defect rate, but the current DGP did not support a general process-variance -> next-day-failure chain.
