# CAPA Evaluation Protocol

Each CAPA contains an effective date, target station, expected mechanism and implementation cost. Evaluation uses pre/post diagnostics, event-study dynamics, placebo-in-time, placebo-in-space, and economic uncertainty propagation. The focal ST07 CAPA has DiD effect about -0.00248, but placebo-in-time p=0.600 and placebo-in-space p=0.364. Final grade: **Inconclusive**.

Observed improvement therefore does not equal an identified causal effect.
