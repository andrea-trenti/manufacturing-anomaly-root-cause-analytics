# Probabilistic CAPA Economics

Economics propagates causal-effect uncertainty, event frequency, loss/event and implementation cost. The focal distribution retains downside: P5 NPV EUR -97,369; P50 EUR 62,325; P95 EUR 318,261; P(NPV>0)=72.76%; CVaR5 EUR -150,116; median payback about 15.5 months.

This is a synthetic decision model, not a plant forecast. Prevention, appraisal, internal failure and external failure are reported separately to avoid mixing Cost-of-Quality categories.
