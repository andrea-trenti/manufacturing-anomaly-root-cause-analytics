# Root-Cause Evidence Framework

Root-cause evidence is graded progressively: raw association, stratified association, adjusted association, temporal precedence, quasi-experimental evidence, and intervention verification. Feature importance and anomaly ranking are not causal proof.

The ST07 case illustrates the rule. Raw operator evidence looked concerning, but adjustment weakened the operator effect. M07B retained moderate adjusted evidence, yet multiplicity control and counterfactual CAPA diagnostics prevent a Strong causal label.
