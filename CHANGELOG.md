# Changelog

## v3.0.0 - defensibility and release engineering

v3 expands the study to 504,000 production events, 18,000 vehicles, 300 days and 14 injected failure mechanisms. The scientific changes already validated in Parts 1-2 are frozen: strict temporal validation, fixed-budget rare-event evaluation, leakage auditing, known-truth RCA recovery, null abstention, censored reliability treatment, CAPA placebo tests and probabilistic economics.

The final release engineering adds a 10-stage resumable pipeline, input/output hashes, machine-readable data contracts, 36 regression/QA tests, claim governance, falsification tables, 8D-style case documentation, reaction plans, runtime scaling, GitHub packaging and archive integrity checks.

Important negative results remain part of the release: random splitting inflates PR-AUC by 63.5%; ST07 CAPA is Inconclusive; the economic distribution has negative P5 and CVaR; and the synthetic study does not claim external industrial validation.
